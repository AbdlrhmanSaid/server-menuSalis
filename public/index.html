مخطط علاقات قاعدة البيانات (Entity-Relationship Diagram)

يوضح هذا المخطط الهيكل التنظيمي للبيانات والعلاقات المتبادلة بين المجموعات المختلفة (Collections) في قاعدة بيانات MongoDB التابعة لـ MenuSalis.

توضيح العلاقات والترابط المنطقي للبيانات:

1. علاقة الشركة بالفروع (Company ──► Branch):
• نوع العلاقة: رأس بأطراف (One-to-Many).
• التفاصيل: ترتبط كل وثيقة فرع بـ Company واحدة إلزامياً عبر حقل company كـ ObjectId. عند حذف فرع، تتم تلقائياً إزالة معرفه من قائمة الفروع المتاحة لجميع المنتجات.
2. علاقة الشركة بقائمة الطعام (Company ──► Menu):
• نوع العلاقة: رأس بأطراف (One-to-Many).
• التفاصيل: كل قائمة طعام Menu ترتبط بمطعم أو شركة واحدة فقط عبر حقل company كـ ObjectId.
3. علاقة قائمة الطعام بالمنتجات (Menu ──► Product):
• نوع العلاقة: رأس بأطراف (One-to-Many).
• التفاصيل: تحتوي قائمة الطعام على مصفوفة من معرفات المنتجات products (Array of ObjectIds)، وبالمقابل يرتبط كل منتج بـ Menu واحدة إلزامياً عبر حقل menu. عند حذف القائمة، يقوم النظام تلقائياً بحذف جميع المنتجات المربوطة بداخلها لحماية سلامة البيانات ومنع حدوث تراكم عشوائي.
4. علاقة المنتج بالفروع (Product ◄──► Branch):
• نوع العلاقة: أطراف بأطراف (Many-to-Many).
• التفاصيل: يملك المنتج مصفوفة لمعرفات الفروع المتاحة availableBranches (Array of ObjectIds) التي يتوفر بها هذا المنتج للزبائن. يجب أن تكون هذه الفروع تابعة لنفس الشركة المالكة للمنيو لضمان صحة البيانات في لوحة التحكم.

الاتصال بنظام الـ WebSockets

يستخدم النظام تقنية Socket.io للبث المباشر لأي عمليات تحديث، إضافة، أو حذف تحدث على الشركات، قوائم الطعام، والمنتجات. يمكنك الاتصال بخادم الويب وسماع الأحداث التالية تلقائياً لتحديث واجهة المستخدم بالزمن الحقيقي.

كود الاتصال المثالي بالعميل (Javascript Client):

Socket.io JS 
import { io } from "socket.io-client";

const socket = io("http://localhost:5000", {
  withCredentials: true,
});

socket.on("connect", () => {
  console.log("Connected to WebSocket Server:", socket.id);
});

// استقبال الأحداث
socket.on("product_created", (newProduct) => {
  console.log("تمت إضافة منتج جديد بالزمن الحقيقي:", newProduct);
});

قائمة الأحداث التي يبثها السيرفر (Emitted Events):

company_created
يبث عند إنشاء شركة جديدة بنجاح. يرسل كائن الشركة كاملة Company Object.
company_updated
يبث عند تعديل بيانات شركة. يرسل كائن الشركة المعدلة كاملة Company Object.
company_deleted
يبث عند حذف شركة. يرسل كائن المعرف المحذوف: { id: "company_id" }.
menu_created
يبث عند إنشاء قائمة طعام جديدة. يرسل كائن المنيو كاملة Menu Object.
menu_updated
يبث عند تعديل قائمة طعام. يرسل كائن المنيو مع الفروع المرتبطة والمنتجات: Menu Object.
menu_deleted
يبث عند حذف قائمة طعام. يرسل كائن المعرف المحذوف: { id: "menu_id" }.
product_created
يبث عند إنشاء منتج جديد. يرسل كائن المنتج كاملاً بعد ملئه (Populated) ببيانات المنيو، الشركة، والفروع المتاحة.
product_updated
يبث عند تعديل منتج. يرسل كائن المنتج المعدل كاملاً مع الفروع المتاحة والمنيو التابع له.
product_deleted
يبث عند حذف منتج من النظام. يرسل كائن المعرف المحذوف: { id: "product_id" }.
